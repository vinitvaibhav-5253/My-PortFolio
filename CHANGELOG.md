# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.3.0] - 2026-09-27

### Changed
- Enhanced portfolio UI with improved styling across all sections
- Upgraded animations and scroll-triggered transitions
- Refined section heading component design
- Improved global CSS with better color palette and spacing

### Fixed
- Animation consistency across all sections

## [0.2.0] - 2026-09-27

### Added
- Web3Forms integration for contact form (primary)
- EmailJS integration as fallback email service
- Direct Gmail / mailto link as final fallback
- Site URL updated to vinitvaibhav.online

## [0.1.0] - 2026-09-27

### Added
- Initial enterprise portfolio build
- Next.js 16 App Router with React 19 and TypeScript
- Tailwind CSS 4 styling with dark theme
- shadcn/ui component library integration
- Framer Motion scroll-triggered animations
- Responsive navigation bar with mobile menu
- Hero section with animated grid background
- About section with education and certifications
- Skills section with categorised skill cards
- Projects showcase with tech stack badges
- Experience timeline section
- Resume download section
- Contact form with dual email service support
- SEO optimization with JSON-LD, Open Graph, and Twitter Cards
- Scroll progress indicator
- Skip-to-content accessibility link
- Google Fonts: Inter, Space Grotesk, JetBrains Mono
- ESLint 9 + Prettier code formatting setup
- Environment variable configuration system
